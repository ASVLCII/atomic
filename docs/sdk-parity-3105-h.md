# SDK builtin parity — slice H (#3105)

## Boundary and evidence

This slice runs a genuine npm-installed Node consumer, not a workspace alias consumer. The existing installed-layout CLI smoke is retained separately; the new `consumer-parity.mjs` never starts the Atomic CLI, uses RPC, reads stdin, or forces process exit. It uses ordinary SDK APIs and real shipped builtin assets. Its child hosts are real Node processes running copied fixtures, not CLI children.

Local execution: macOS arm64, Node **26.8.2**. No remote CI, Windows, Linux, or Node 22 execution is claimed here.
